## 2. Consensus Assessment — **SPLIT (asymmetric structure)**

Agreement is high on *different questions* than the ones that set the price:

- **Asset quality — HIGH consensus.** Sector, Growth, Alt Data and even the Short Analyst concede the RASolute-302 data (mOS 13.2 vs 6.7, HR ~0.40, 60% mortality reduction, 1.2% discontinuation) is verified, not promotional. Value calls it "superb science." This is not in dispute.
- **Risk magnitude — HIGH consensus.** Six agents (Fin, Nonfin, Quant, Macro, Short, ESG) independently land on the same list: 66% vol, ~49% realised drawdown, single-asset binary, accelerating burn, chronic dilution, insider selling.
- **Valuation — LOW/SPLIT.** Value says −36% downside to intrinsic ($125); Growth says +32% upside to median target ($260). That is a **2.1x dispersion in fair value** between two competent analysts. Quant is neutral, Short has "no edge."

**Conflict resolution.** The framework says risk flags outrank bullish views — but the Short Analyst specifically **rejects** the fraud/forensic case, so there is no disqualifying flag to override. What remains is a *margin-of-safety* conflict. Value's case wins on evidentiary weight (it is the only agent that built an explicit probability-weighted model), but it is not a "do not own" verdict — it is a "do not own *at this size, at this price*" verdict. Growth's case is the reason not to pass entirely: it is the only agent anchoring on 2028–2030 consensus arithmetic rather than scenarios.

**Read:** high-quality asset, contested price, discontinuous payoff. Size to the minimum of the two valuations, not the midpoint.

## 3. Position Sizing Recommendation — **0.75% starter → 1.5% target (hard cap 2.0%)**

Not the 3–5% "high conviction" bucket. Three reasons:

1. **Kelly is negative at current prices.** Using a blended distribution (p↑≈45%, avg win +50%; p↓≈55%, avg loss −45%), *f* = 0.45 − (0.55/1.11) = **−0.05**. Full Kelly says zero. A token, catalyst-gated position is the only defensible fractional-Kelly expression.
2. **Volatility budget dominates.** At 66% annualised vol, a 1.5% weight contributes **~1.0% of portfolio volatility** — the same risk as a 10% position in a 10%-vol asset. A 0.75% starter contributes ~0.5%. Sizing by capital here would badly misstate the risk taken.
3. **Payoff math is survivable, not compelling.** 1.5% × −50% bear = **−75bp** portfolio hit; 1.5% × +50% = +75bp. Asymmetric appetite belongs elsewhere; this is an option on 1L PDAC, not a core compounder.

**Structure:** 0.75% now (½ of starter before the 4-Nov print), build to 1.5% only on confirmation — see §5. Max 2.0% and only if RASolute-303 de-risks.

## 4. Portfolio Fit Analysis

- **Sector concentration:** Healthcare/biotech. The offsetting good news is that RVMD is **not** biotech beta — 0.39 to XBI, 0.24 to SPY, and near-zero to the actual comparables (AMGN 0.12, NUVL −0.09, ERAS 0.09) because R² is only 0.155. So it adds **single-name event risk, not sector crowding**. If the book is already long XBI/IBB, this is a diversifying addition; if the book already holds binary oncology names, treat it as additive concentration.
- **Factor exposure — the real cost.** RVMD tilts the portfolio toward **long-duration growth, negative value, negative quality, high volatility** simultaneously. With the 10Y at 4.99% and the Fed expected to hike in December, Macro's −15–18%-per-75bp estimate means this position *increases* the book's rate-shock sensitivity. Any existing growth/duration sleeve should be reduced by roughly the same risk contribution.
- **Correlation:** no hedge value against AMGN — the two are effectively independent bets (0.12), so RVMD does not offset RAS-class exposure and does not substitute for it either.
- **Factor-model caveat:** Standard value/quality/low-vol scores are artifacts of near-zero revenue (F-Score 1/9, Altman "distress," P/B 22.9x). **Do not let a quant screen reject this name on those scores** — and equally, do not let it accept the name on momentum, which is only +4.84% after a 5x.
