### Data Limitations
1. **Google Trends** is search *interest*, not units or revenue — it proxies awareness/intent. Data lags **~1–2 weeks** (series ends 1 Nov, so the late-Oct selloff is only partially captured). "Dell AI server" has a near-zero base and should not be weighted heavily.
2. **Patents (USPTO) and web traffic (SimilarWeb): both FAILED.** No R&D-intensity or site-visit trend for this report. Two attempts each, then abandoned per budget.
3. **Job postings:** qualitative proxy only — a LinkedIn headline count with **no time series**, so no acceleration read.
4. **Social sentiment:** three-or-four Reddit thread titles, not a quantitative score. Anecdotal.
5. **News sentiment:** keyword-frequency scoring, not analyst-verified tone; vulnerable to headline clustering.
6. **Guidance inconsistency:** secondary sources cite an FY27 revenue guide of $165–167B alongside a $49.2B Q3 consensus — these are unreconciled (the FY guide has evidently been raised since). Treat the absolute guidance figures as approximate; the *direction* (raised, AI-led) is well-supported.
7. **Confidence is capped at Medium** by two dead data feeds and the absence of any real-time ISG demand proxy — the segment that actually drives the thesis.

*Alt data is a leading indicator, not a definitive one. This report informs a position; it does not replace fundamental work on pricing power and memory cost pass-through.*
