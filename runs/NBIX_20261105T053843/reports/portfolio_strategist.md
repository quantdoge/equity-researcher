## 3. Position Sizing Recommendation: **1.5% initial → 3.0% maximum**

**Do not size this as a low-beta name.** Beta reads 0.36 (5y monthly) to 0.63 (1y daily); realised vol is 36.4%. Beta-based sizing would understate NBIX's VaR contribution by roughly an order of magnitude.

**Kelly arithmetic:** probability-weighted value — 25% bull $248 / 50% base $185 / 25% bear $125 = **$185.75 (+12%)**. Edge/σ² = 0.12 / 0.365² ≈ 0.90 (full Kelly ~9% of book). Applying a 1/4-to-1/3 fraction for estimation error, single-asset concentration (72% of revenue in one molecule) and dated binary events gives **2–3%**. I start at **1.5%** because the entry price is 11% *above* the level at which Value would size properly.

**Why not larger:** 2% × 25% bear-case drawdown = **0.50% of portfolio at risk** — tolerable. At 4%, the same path costs 1.0% of book on a name with four >10% single-day gaps in three years.
**Why not smaller/pass:** the fraud tail is removed, quality factor is top-quartile, the patent runway extends to 2038–2040, and consensus already models the cliff (+2.8% 2029 revenue growth). Passing forfeits a positive-expectancy, genuinely uncorrelated asset.
