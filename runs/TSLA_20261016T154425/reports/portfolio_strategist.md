## 3. Position Sizing Recommendation

**New capital: 0% — PASS.** **Existing holders: reduce toward ≤1% (or zero into strength).**

With edge ≤ 0, the Kelly-optimal long size is zero. The bear edge is real but the payoff distribution is hostile to shorts (2.2–2.3 beta, 45–59% vol, retail cult vector, binary catalysts both directions, borrow/financing costs) — so even a bear expression should be sized as a *small, defined-risk satellite*, not a conviction short.
